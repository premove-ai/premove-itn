Premove is an open-source effort to reduce latency in voice agents. Premove ITN
is one part of that broader work, focused on turning spoken values into useful
written forms.

The broader project is in active development, and its documentation is in
progress. The Premove ITN guides are available now.

## Explore Premove ITN

[Premove ITN](/itn/) is an open-source inverse text normalization project
for English voice-agent transcripts. It turns spoken values into written forms
such as dates, amounts, phone numbers, URLs, and identifiers. A contextual
model chooses among valid candidates so the result fits the sentence.
