# Premove ITN v0.2.0 targeted release comparison

This document records a small, targeted smoke evaluation of the contextual
TIME-versus-identifier behavior changed in v0.2.0. It is release evidence for
the scorer update, not a replacement for the frozen benchmark.

## Result

The v0.1.0 output matched the intended result on **2/10** rows. The v0.2.0
output matched the intended result on **10/10** rows.

The queue-position transcript from the original exploratory list is excluded:
its identifier/time labels were semantically inconsistent, so it is not a valid
accuracy example.

## Methodology

The same 10 transcript strings were sent to the public CLI from clean Python
3.11 environments:

1. Create one clean virtual environment for each release.
2. Install the published wheel with `premove-itn==0.1.0` or
   `premove-itn==0.2.0`.
3. Pipe the 10 transcripts to `premove-itn` in the same order.
4. Compare each output with the intended contextual interpretation above.

Each release resolves its own pinned Hugging Face model snapshot on first use.
The comparison uses the public package and model artifacts, not a checkout or a
development model. The transcript strings are synthetic and were selected to
exercise an identifier in one context and a time in another.

## Reproduction

Run one release at a time from a clean Python 3.11 environment:

```bash
uv venv --python 3.11 /tmp/premove-v020
uv pip install --python /tmp/premove-v020/bin/python \
  --only-binary=:all: premove-itn==0.2.0
/tmp/premove-v020/bin/premove-itn <<'EOF'
send someone to desk six forty after lunch
we can start the demo around nine twenty
they moved me into cabin eight fifteen today
schedule the technician for eleven forty five and send them to unit two ten
I need bus four twenty but I won't get there until four twenty
our table is seven thirty and dinner starts at eight ten
try locker twelve oh six, I'll be there at twelve oh six
our table number is seven thirty and dinner starts at eight ten
the courier marked package twenty one forty and said he'd arrive around twenty one forty
take elevator three twelve, then meet me downstairs at three twelve
EOF
```

Replace `0.2.0` with `0.1.0` and use a separate environment to reproduce the
baseline. The first invocation downloads about 1.6 GB of model files; later
initializations use the Hugging Face cache for that pinned revision.

## Limitations

- This is a 10-row targeted smoke set, not a statistically representative
  production evaluation.
- The expected outputs are contextual adjudications. They do not prove that
  every phrase with the same words has the same meaning.
- The two releases use different scorer artifacts, so this comparison measures
  release behavior rather than isolating a single training or parser change.
- The deterministic Rust candidate layer bounds the available written forms;
  the scorer cannot select an output that Rust does not generate.
- Results can differ if a caller uses a local artifact, a different revision,
  or a modified candidate graph.
